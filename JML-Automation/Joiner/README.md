# M365 Joiner Automation

PowerShell automation for Microsoft 365 onboarding.

## Planned Scripts

### Invoke-Onboard.ps1

Features:

- Create Entra ID account
- Assign manager
- Populate user attributes
- Assign licences
- Add group memberships
- Configure mailbox
- Generate audit logs
