# M365 Mover Automation

PowerShell automation for internal user role changes.

## Planned Scripts

### Invoke-Mover.ps1

Features:

- Manager changes
- Department transfers
- Job title updates
- Group membership review
- Dynamic group migration
- Licence reassignment
- Audit logging
