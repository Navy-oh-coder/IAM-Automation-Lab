# M365 Offboarding Automation

PowerShell automation for Microsoft 365 offboarding.

## Entra ID Script

Invoke-SalixOffboard.ps1

Features:
- Disable account
- Remove manager
- Revoke sessions
- Remove group memberships
- Remove licences
- Export audit logs

## Exchange Script

Invoke-SalixOffboard_Exchange.ps1

Features:
- Convert mailbox to shared
- Remove distribution groups
- Remove mail-enabled security groups
- Export audit logs
