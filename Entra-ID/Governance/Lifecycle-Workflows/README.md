# Lifecycle Workflows

## Purpose

Document lifecycle-triggered identity governance using Microsoft Entra Lifecycle Workflows.

## Current status

**Documentation only in this repository.** The planned management script is not present. This status does not describe or negate any Lifecycle Workflows configured in an external tenant.

## Planned scope

- Joiner, mover and leaver workflow designs.
- Supported task configuration and monitoring.
- Notifications and workflow reporting.
- HR feed or service-management integration where appropriate.

## Validation and limitations

Document task-level success and failure evidence, retries, exceptions, licensing and permissions. Distinguish workflow execution records from proof that every downstream action succeeded.
