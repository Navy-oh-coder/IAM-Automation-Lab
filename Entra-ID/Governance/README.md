# Entra ID Governance

This area covers how access is requested, approved, reviewed, assigned and removed over the identity lifecycle.

## Areas of focus

- Access Reviews and access certification.
- Entitlement Management and Access Packages.
- Group ownership and membership governance.
- Lifecycle Workflows and lifecycle-triggered actions.
- External collaboration and guest access governance.

## Current status

The subfolders currently provide planning documentation. Capabilities described as planned must not be treated as implemented automation unless corresponding code and validation evidence are added.

## Design principles

Choose controls according to the access scenario: dynamic groups for attribute-driven membership, Access Packages for governed access requests and assignments, and Lifecycle Workflows for supported lifecycle-triggered tasks. Document overlaps, exceptions, ownership and removal behaviour.
