# Entra ID Security

## Scope

This workstream covers identity security controls and the evidence needed to assess their effectiveness.

Planned areas include:

- Conditional Access policy design, coverage and exclusions.
- MFA enforcement and authentication-method review.
- Privileged Identity Management and standing privilege reduction.
- Emergency access account safeguards.
- Identity Protection risk detection and response.
- Administrative account separation and privileged access review.

## Current status

This README is a planning and scope document. It does not claim that security scripts or configuration exports exist in this folder, nor that controls have been independently validated.

Tenant configuration and implementation evidence should be documented separately from repository code. Do not commit credentials, tokens or sensitive tenant exports.

## Validation

Record control scope, exclusions, licensing requirements, required permissions, test outcomes and known gaps. See the [programme roadmap](../../docs/ROADMAP.md) for planned work.
