# Access Reviews

## Purpose

Plan identity governance reviews for groups, guests and other appropriate access scopes.

## Current status

**Planned.** This folder documents intended access-review functionality; the listed `Start-AccessReview.ps1` script is not present.

## Planned scope

- Group and guest access reviews.
- Manager attestations and access certification.
- Review-result reporting.
- Future consideration of approved remediation and dynamic review scopes.

## Validation and limitations

Define review ownership, frequency, reviewer fallback, decisions, remediation behaviour and evidence retention before implementation. Verify licensing and permissions for the target environment.
