# M365 Joiner Automation

## Purpose

Plan onboarding automation for Microsoft 365 and Entra ID.

## Current status

**Planned.** This folder currently contains design documentation, not an implemented onboarding script. The listed capabilities are intended scope, not delivered functionality.

## Planned scope

- Create Entra ID account and assign manager.
- Populate user attributes and assign licences.
- Add appropriate group memberships and configure mailbox.
- Generate onboarding audit evidence.

## Future considerations

- HR or ServiceNow integration.
- Automated welcome communications.
- Attribute-driven dynamic group assignment.
- Integration with supported Lifecycle Workflows.

## Validation and limitations

Define the authoritative source, required permissions, failure handling, approvals and audit evidence before implementation. Test in a non-production environment.
