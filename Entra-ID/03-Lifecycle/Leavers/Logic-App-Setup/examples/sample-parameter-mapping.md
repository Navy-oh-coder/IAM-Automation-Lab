# Sample Logic App parameter mapping

This is an expression reference, not a replacement for the Logic App generated by the Entra custom task extension wizard.

## Extract the user's UPN

Use this expression in the Logic App designer:

```text
triggerBody()?['data']?['subject']?['userPrincipalName']
```

## Pass the UPN to Azure Automation

In the Azure Automation Create job action, map the runbook parameter object:

```text
addProperty(
  json('{}'),
  'UserPrincipalName',
  triggerBody()?['data']?['subject']?['userPrincipalName']
)
```

The PowerShell runbook declares a parameter named UserPrincipalName. Keep the mapping key aligned with that parameter.

## Verify it

1. Invoke the extension from an actual Lifecycle Workflow test run.
2. Open Logic App run history and inspect trigger input using an approved test identity.
3. Open the Azure Automation job input and confirm the parameter is populated.
4. Avoid copying real user information into public issue reports or source-control examples.

With Wait for job disabled, a successful Create job action means the job was submitted; it does not prove that the runbook completed successfully.
