# Microsoft 365 Copilot and Agent Governance

This workstream focuses on identity, data protection and operational controls that support the safe adoption of Microsoft 365 Copilot and AI agents.

## Areas of focus

- SharePoint permissions, oversharing and access boundaries.
- Microsoft Purview readiness, sensitivity labels and data protection.
- Identity and permission boundaries for Copilot and agents.
- Agent inventory, ownership, authentication and lifecycle.
- Application permissions, credentials, monitoring and retirement.
- Governance evidence, exceptions and readiness reporting.

## Current status

The repository currently contains Copilot readiness planning documentation. The planned assessment script is not present, and this README does not claim that any tenant controls have been implemented or validated by this repository.

## Engineering approach

Build on sound identity governance and data access controls. Document prerequisites, licensing, permissions, control owners and validation evidence. Treat agent governance as a lifecycle and identity problem as well as a data governance problem.
