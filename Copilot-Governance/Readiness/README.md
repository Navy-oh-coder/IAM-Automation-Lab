# Copilot Readiness

## Purpose

Plan assessment and reporting to support Microsoft 365 Copilot adoption.

## Current status

**Planned.** The listed `Invoke-CopilotReadinessAssessment.ps1` script is not present.

## Planned scope

- Licence and user readiness.
- SharePoint permissions and oversharing.
- Microsoft Purview readiness and data governance.
- Sensitivity label and data exposure analysis.
- Security posture and readiness reporting.

## Future considerations

- Validated data collection and scoring.
- Evidence-based reporting for decision makers.
- Agent inventory and governance as agent capabilities are adopted.

## Validation and limitations

Define the scope, data sources, permissions, licensing, scoring method and known blind spots before implementation. Readiness reporting must not be treated as proof that Copilot can access only appropriate information.
